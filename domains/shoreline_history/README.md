# Domain 2 — Shoreline History

## Purpose
Tracks historical shoreline positions to measure coastal retreat, advance, or stability.

## Extraction Method (intended — not yet implemented)
MNDWI = 0 contour from Landsat SR imagery; cloud/shadow masking via QA_PIXEL.  
Projected to UTM Zone 44N (EPSG:32644) for metric displacement measurement.

## Synthetic Data (current)
Generated by `processing/generate_synthetic.mjs` (seed 42).  
Three scenarios: **erosion** (−1.2 m/yr trend), **accretion** (+0.8 m/yr), **stable** (0.0 m/yr).  
Records: 156 (13 dates × 4 transects × 3 scenarios).

⚠ **SYNTHETIC — not measured shoreline positions.**

## Regenerate
```bash
node domains/shoreline_history/processing/generate_synthetic.mjs 42
```

## Limitations
- Real shoreline pipeline requires Landsat imagery download
- Uncertainty ±15 m from mixed pixels at 30 m resolution
- Synthetic model does not reproduce storm-event geomorphology
