# Domain 4 — Rainfall & Weather

## Purpose
Supplies precipitation and meteorological forcings that influence coastal erosion
via storm runoff, wave setup, and sediment mobilisation.

## Intended Real Sources
- **GPM IMERG Final Run** (NASA) — 30-min, 0.1° × 0.1°, mm/hr
- **ERA5 Reanalysis** (ECMWF/CDS) — hourly, ~31 km, multiple variables

## Synthetic Data (current)
Generated by `processing/generate_synthetic.mjs` (seed 42).  
Daily records 2015–2024 (3653 days).  
Seasonal pattern based on Tamil Nadu monsoon climatology; Poisson rain events.

Features: `rainfall_mm_per_day`, `accum_7d_mm`, `accum_30d_mm`,
`max_intensity_mm_per_hr`, `wind_speed_kmh`, `wind_dir_deg`, `temp_c`, `pressure_hpa`.

⚠ **SYNTHETIC — not GPM or ERA5 measurements.**

## Regenerate
```bash
node domains/rainfall_weather/processing/generate_synthetic.mjs 42
```

## Limitations
- Real download requires NASA Earthdata + Copernicus CDS credentials
- Synthetic values not calibrated against any station record
- No forecast capability in this release
