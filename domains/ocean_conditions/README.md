# Domain 5 — Ocean Conditions

## Purpose
Provides wave energy, tide level, and storm-surge indicators — the primary
hydrodynamic drivers of coastal erosion in the Bay of Bengal.

## Intended Real Sources
- **INCOIS Wave Watch III / ERA5 Waves** — Hs, Tp, wave direction
- **TPXO9 Tidal Prediction** (OSU) — M2, S2, N2, K2, K1, O1 constituents

## Synthetic Data (current)
Generated by `processing/generate_synthetic.mjs` (seed 42).  
6-hourly records 2015–2024 (14 612 time steps).  
Tide: simplified M2 (A=0.55 m, T=12.42 h) + S2 (A=0.15 m, T=12 h) harmonics.  
Waves: seasonal mean Hs scaled to Bay of Bengal climatology + storm events (3 % probability).

Variables: `Hs_m`, `Tp_s`, `wave_dir_deg`, `wave_power_kw_per_m`, `tide_level_m`,
`tidal_range_m`, `storm_surge_flag`.

⚠ **SYNTHETIC — not INCOIS or TPXO measurements.**

## Regenerate
```bash
node domains/ocean_conditions/processing/generate_synthetic.mjs 42
```

## Limitations
- Real download requires INCOIS API access or ERA5 wave download pipeline
- Only M2+S2 tidal constituents; Bay of Bengal real tides have ~6 major constituents
- Nearshore current data not included
