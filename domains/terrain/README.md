# Domain 3 — Terrain

## Purpose
Provides elevation, slope, aspect, and coastal proximity features for erosion-risk assessment.

## Intended Real Source
ALOS World 3D – 30 m (AW3D30), JAXA.  
URL: https://www.eorc.jaxa.jp/ALOS/en/aw3d30/  
Vertical datum: EGM96. CRS: EPSG:4326. Resolution: 30 m.

## Synthetic Data (current)
Generated by `processing/generate_synthetic.mjs` (seed 42).  
100×100 grid at 30 m cells; coastal gradient + dune ridge + low-frequency noise.  
Derived: slope (finite-difference gradient) and aspect (atan2).

⚠ **SYNTHETIC — not a real DEM.**

## Regenerate
```bash
node domains/terrain/processing/generate_synthetic.mjs 42
```

## Limitations
- 30 m resolution insufficient for sub-metre coastal morphology
- Real AW3D30 download not yet implemented
- Vertical datum and tidal correction not applied to synthetic surface
