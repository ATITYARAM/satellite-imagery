# Domain 3 — Terrain

## Study area
Shanghumugham–Valiyathura–Poonthura coast, Thiruvananthapuram, Kerala.

## Synthetic development dataset
`data/synthetic/terrain_grid_2015_2025.json` contains an illustrative 15 × 15 grid (225 cells, nominal 30 m spacing) with elevation, slope, aspect, coastal proximity, and roughness. The public compatibility copy is `public/domains/terrain/data/synthetic/terrain_grid.json`.

**Synthetic only:** this is a procedural coastal gradient, not a measured DEM. Replace it with a clipped, quality-checked Copernicus DEM before scientific use.
