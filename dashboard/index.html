ORIGINAL PROBLEM STATEMENT

"Create a satellite-image analytics system to monitor and predict coastal erosion patterns. The solution should integrate spatial datasets such as maps, satellite imagery, terrain, rainfall, infrastructure, and field records to generate meaningful decision layers. The outcome may include risk maps, priority zones, dashboards, and validation using historical records or expert-labelled ground truth."

PROJECT OBJECTIVE

The system processes five independent domains (Satellite, Shoreline History, Terrain, Weather, Ocean). Each has its own processing pipeline producing standardized outputs, which are then combined spatially and temporally. This dataset is passed to Machine Learning (Random Forest baseline, XGBoost main). The current synthetic demonstration targets future_shoreline_change_m (PROVISIONAL SYNTHETIC DEMONSTRATION TARGET).
